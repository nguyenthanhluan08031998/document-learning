Ba kiểu API đồng bộ

REST xoay quanh tài nguyên và HTTP chuẩn. GraphQL để client tự chọn dữ liệu qua một schema. gRPC gọi hàm từ xa với hợp đồng Protobuf và HTTP/2. Cả ba đều là request–response: bên gọi chờ kết quả.

Khi nào chọn

REST

  • API công khai cho bên thứ ba.
  • CRUD đơn giản, cần cache CDN.
  • Đội ngũ đa dạng, cần dễ tiếp cận.

GraphQL

  • Frontend nhiều màn hình, mỗi màn cần dữ liệu khác nhau.
  • Mobile cần giảm số request và dung lượng.
  • Gom nhiều service phía sau thành một API (BFF).

gRPC

  • Giao tiếp nội bộ giữa microservice.
  • Cần độ trễ thấp, nhiều ngôn ngữ, hợp đồng chặt.
  • Cần streaming hai chiều.
Một hệ thống hay dùng cả ba: REST hoặc GraphQL hướng ra ngoài, gRPC giữa các service bên trong. Xem sơ đồ ở trang Tổng quan.
